Findings
--------
1. U10 channels AN0-AN10 map directly to MAP2, VOLT, O2, MAP, CTS, TPS,
   PUMPVOLT, DIAG, MAT, ESC and VMAF respectively.

2. Normal firmware explicitly requests selectors $10, $20, $40, $50, $60,
   $70, $80 and $A0. It does not explicitly request $00/MAP2, $30/MAP, or
   $90/ESC.

3. Factory test $FDB5-$FDC5 scans selectors $00-$B0 and stores 12 raw samples
   at $017B-$0186. The retained schematic does not identify a corresponding
   AN11/external input for selector $B0, so it remains unresolved.

4. The common A/D routine $F1BE-$F1DF returns an 8-bit value through temporary
   RAM $0064. Dedicated raw and processed variables differ by channel and are
   explicitly separated in the new reference.

5. AN1 is labelled VOLT on the schematic and derives from VIGN conditioning,
   although firmware treats $007E functionally as battery voltage. AN6
   PUMPVOLT is a separate channel stored at $007F.

6. MAT is complemented before storage at $012B/$0060. VMAF/AN10, not MAP,
   feeds the supplied image's main MAF/airflow/load path.

Source and baseline impact

Conclusion
----------
Step 133 establishes the complete visible U10 channel map and the actual
image-specific acquisition schedule while leaving U10 reference accuracy,
selector $B0, unused-channel roles, and custom-device behavior unresolved.
