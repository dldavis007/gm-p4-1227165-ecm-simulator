Scope and integration
---------------------

$FF00 COP restart. A factory IRQ now follows the complete represented path
from the startup flag and IRQ branch through the final wait-loop handoff.
Ordinary scheduler execution remains bypassed while L0047 bit 7 is set.

Raw mode branches
-----------------
The translation does not trust inconsistent semantic labels around the mode
branches. TST L0048 selects a complete-byte zero path. A nonzero value with
bit 0 clear selects the async-pulse, checksum and all-off path. A nonzero
value with bit 0 set selects the A/D, output-exercise and fuel/spark path.

The zero path preserves the conditional L0031 bit-1 toggle and the L0049
bit-2 control of MPU CSR bit 2. The nonzero-even path writes 197 to L3FF2,
temporarily sets the CSR high-byte bit 2, calculates the modulo-65536 sum of
exactly L0000..L002D into L0175, and performs LF32E's single COP restart for
this 46-byte invocation. Both paths converge on the emitted all-off writes:
zero synchronous fuel, masked parallel I/O and $7000 at all six PWM addresses.

A/D and output exercise
-----------------------
The low-bit-set path captures twelve HAL-supplied A/D bytes in channel order
at L017B..L0186. Every fourth factory count, it saves the L017F coolant sample
to L0187 or L0188 according to L0031 bit 0 and then toggles that bit. No exact
electrical transfer function or resistor-network identity is inferred.

When the low nibble of L0172 is zero, the PWM selector preserves the emitted
unsigned arithmetic: values above 32 first subtract $30 with 8-bit wrap; the
folded result selects $D200 below 16, $D066 at 16, and $D39A above 16. The
selected word reaches L3FCC and L3FD2/L3FD4/L3FD6/L3FD8/L3FDA. The following
CSR and $4004 bit changes and the rotate-left IAC phase at L0179/$4002 are
stored as raw writes without assigning physical polarity.

Factory fuel and spark
----------------------
Every low-bit-set pass stores L3FC0/4 at L0177. Reference periods above 655
select fuel 655, dwell 327, quarter-period fire, and zero EFI delay. Periods
328 through 655 select fuel 327, dwell 262, zero fire offset and zero delay.
Periods below 328 select fuel 66, dwell 197, wrapped negative quarter-period
fire and EFI delay 66. Equality boundaries and 16-bit wrapping are regression
tested explicitly.
