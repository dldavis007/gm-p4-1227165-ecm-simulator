Translation rules
-----------------
Executable comparisons and branches outrank comments.  Notable literal
details retained by the C implementation include:

- all threshold comparisons preserve strict versus inclusive behavior;
- eight-bit diagnostic counters wrap as source bytes;
- the ERR32 timer is a big-endian 16-bit value at L00AE/L00AF;
- high-load and several other ERR32 disqualifiers decay that timer by two,
  saturating at zero, while a low-coolant path clears it immediately;
- the ERR32 startup-switch case can set the candidate bit from L0041 bit 5
  while leaving the existing timer unchanged;
- the $E6B8 `ASLA`/`BPL` decision is modeled from the resulting condition
  flags, which tests original L0034 bit 6 regardless of the nearby comment;
- L0040 bit 0 is consumed and cleared by the ERR41 block;
- ERR44/45 clear the forced-integrator bit before returning.
