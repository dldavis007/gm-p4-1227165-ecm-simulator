Emitted vector table
--------------------
Step 119 preserves the eight literal words at $FFF0..$FFFE:

  $FFF0 -> $6000

The implementation indexes only even addresses in that exact interval and
rejects other addresses. It does not assign exception names from comments.

Represented dispatch
--------------------
The $FFF2 target enters the existing $C9F4-facing IRQ model. With the factory
flag clear it executes the ordinary 6.25-ms scheduler; with L0047 bit 7 set it
uses the Step-117/118 factory path. The instruction at $F27B is the single
emitted RTI byte, so $FFF4 records an immediate return without fabricated
state changes.

Each of the four $C800 destinations records a reset/startup request. It does
not automatically clear RAM or claim to reproduce processor, COP, clock-fail,
power-hold, or restart circuitry. The two $6000 destinations are outside the
supplied PROM region and remain explicit external-code boundaries.

SWI boundary handling
---------------------
Existing modeled SWI sites now record their exact instruction addresses:
$CDCD for the missing-reference wait, $D6EA for ignition powerdown, $FD03 for
factory low-power timeout, and $FDB3 for factory diagnostic rejection. The
assembled bytes prove those SWI instructions. The listing comments do not by
themselves prove which raw vector slot the relevant processor assigns to SWI,
so Step 119 deliberately does not connect those events to $FFF0 or $FFF6.

Boundaries and coverage conclusion
----------------------------------
Processor exception-entry mechanics, external code at $6000, reset electrical
effects, and the absent optional HUD ROM remain boundaries. Step 119 closes
the vector-table item identified by the Step-110 whole-image audit, but does
not claim whole-machine or byte-for-byte equivalence where hardware or ROM
evidence is absent.
