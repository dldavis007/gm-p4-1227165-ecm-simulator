Signature contract
------------------
The signature uses explicitly reduced 32-bit FNV-1a arithmetic.  It does not
hash C structures or native integers.  Each 6.25-ms post-IRQ snapshot includes
profile segment/tick, source RAM $0000-$01FF, raw MPU $3FC0-$3FFF, raw I/O
$4000-$400F and $5000.  Final selected scheduler counters are serialized as
u32 values most-significant byte first.

This makes the contract independent of host padding, host endianness, 32/64-bit
unsigned-long width, console formatting, and floating-point trace text.  See
STEP104_SIGNATURE.txt for the exact ordered field list.
