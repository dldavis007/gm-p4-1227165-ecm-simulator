Translated behavior
-------------------
Step 116 connects the Step-115 completed-message buffer to $CB5F..$CBB4.
SCI reception sets L0046 bit 3 and copies the accepted mode/control bytes, but
does not set the scheduler Mode-4 flag. A later scheduler pass examines L0151.

On the first pass for Mode 4, $CB72 sets L0035 bit 3. L0154 bit 6 clears the
five error bytes and immediately stores LF3A7's checksum. Bit 5 sets L00F3
bit 2 and writes 255 to the current IAC position. Bit 4 calls LF434 to reset
the SAM words and sixteen BLM cells. The prior-Mode-4 test prevents all three
entry commands from repeating on subsequent passes.

When the completed mode is not 4, $CBA4 clears the Mode-4 flag, L0036 bit 0,
L003F bit 0 and the L00B4 spark-feedback counter. Existing fuel, spark, AFR,
diagnostic and Segment-1 output consumers continue to read the ten received
command bytes from $0152..$015B.

The one-second path at $CBCA increments L0171. Equality at 30 is retained;
only a value greater than 30 clears L0151 to force received Mode 0. Mode-4
exit then occurs on the following scheduler pass.
