Odd minor-loop ordering
-----------------------
The odd 12.5-ms Air/Fuel branch now enters $D6D1 before the previously wired
load/fuel chain. Ignition on resets L008B:L008C to zero and continues through
$D727. Ignition off advances the timer. At count 8 it clears the source mode
state, the run-time word, engine-running state, and associated latches. If the
engine had been running, LF447 bounds the two SAM high bytes to 118..150 and
commits them to the 16 BLM cells, with the second SAM value selecting cell 0.

At LC012=$0385 the source enters the SWI loop at $D6EA before $D727 and before
the fuel chain. The PC port exposes exactly that point as one latched HAL event.
It does not claim to model ECM keep-alive circuitry. Once latched, later calls
to the PC IRQ entry return without executing ECU work.

The literal $D727..$D769 tail is retained: low raw TPS while running sets the
enabled error state, a non-running engine initializes L0086:L0087, and the
image's $FF/$00 extreme positive TPS-delta test sets L0034 bit 5.

Even minor-loop IAC ordering
----------------------------
The $D370 reset/park producer runs on the even 12.5-ms path after the existing
reference/RPM/dwell/spark producer. The existing IAC motor service remains the
6.25-ms consumer. Reset first forces the modeled position to 255 and commands
closing. At zero it changes to the open phase and commands toward LC62F=144.
Completion sets L0002 bit 4. If ignition has returned, LD335 restores its
startup command state. The source's above-park edge case commands +127 steps;
it is not silently treated as completion.

Historical replay isolation
---------------------------

PC-only replay switch that suppresses the newly connected lifecycle producer.
Normal reset leaves the live Step-111 path enabled. The switch is neither ECU
RAM nor target behavior.
