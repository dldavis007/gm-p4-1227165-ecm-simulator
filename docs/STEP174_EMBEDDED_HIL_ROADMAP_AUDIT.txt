BUA / GM 1227165 STEP 174 - EMBEDDED AND HIL ROADMAP AUDIT
=========================================================

Purpose
-------
Step 174 converts the existing migration architecture into a phased,
target-neutral embedded/HIL implementation roadmap. It changes no C source,
tests, calibration, executable behavior or frozen signature.

Roadmap content
---------------
- Target selection is an explicit Phase-0 decision; no MCU, compiler, board or
  transceiver is silently selected by this audit.
- F0-F4 responsibilities govern every phase and keep simulator plants and
  unresolved custom-device behavior outside the translated core.
- Phases cover target-compiler portability, scheduler/timebase, raw inputs,
  shadow-first outputs, communications, retained startup/power, HIL, and
  separately authorized physical integration.
- Every phase has evidence-backed exit criteria, and every migrated seam has a
  traceability record covering authority, target resource, verification,
  unresolved limits and safety behavior.
- Stop conditions prevent target convenience, missing device semantics or
  absent ROM from being turned into fabricated firmware behavior.

Documentation integration
-------------------------
The root README, documentation hub, status page and history index link the new
roadmap. The C-port architecture chapter now describes the actual Step-170
Makefile gate and links the implementation roadmap.

Scope preservation
------------------
Step 171 remains the evidence-supported behavioral closure. Step 174 plans a
separate engineering phase; it does not claim cycle-exact emulation, electrical
equivalence, production safety qualification or implementation of U9/U11/U12,
selector `$B0`, `$5800`, or `$6000` boundaries.
