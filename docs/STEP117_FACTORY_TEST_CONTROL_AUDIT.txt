Battery/ignition branch correction
----------------------------------

translation. Battery values at or below 40 increment a timer below 160 and
reach SWI when the timer is already at least 160. Values from 41 through 89
preserve a nonzero timer. Values at or above 90 clear it. When the FMD low-two
mode value changes, the code stores the new mode, clears the serial bit count
and factory minor count, and primes the table index to $FF.
