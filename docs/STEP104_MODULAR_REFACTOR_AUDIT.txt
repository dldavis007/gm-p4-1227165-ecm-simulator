BUA / GM 1227165 STEP-104 MODULAR REFACTOR AUDIT
================================================

Scope
-----
This change reorganizes the frozen Step-104 PC harness.  It does not claim a
new behavioral step and does not alter calibration semantics, translated ECM
behavior, simulated hardware behavior, regression stimuli, or runtime output.

Architecture
------------
main.c retains int main(void) and includes implementation fragments in their
original Step-104 order.  The result remains one C translation unit.

src/        translated ECM behavior and scheduler-facing support
simulation/ PC-only integrated driving model
tests/      regression-only models and regression entry points
docs/       frozen baseline and verification evidence
build/      generated artifacts

Why one translation unit is retained
------------------------------------
The frozen source intentionally uses many static functions and file-local
objects.  Preserving one translation unit avoids broadening linkage, adding
duplicate state, or introducing declarations that could silently change C89
integer conversions or call behavior.  The .inc.h suffix prevents build tools
from compiling the fragments as independent .c files.
