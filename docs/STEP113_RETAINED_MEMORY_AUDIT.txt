Translated behavior
-------------------
LF3A7 at $F3A7 initializes D to one and adds exactly five bytes, L0005 through
L0009, using 16-bit carry propagation. The helper returns that wrapped 16-bit
checksum.

The invalid-retained path at $C8F5 clears L002D down through L0001. The emitted
loop does not clear L0000. It recomputes LF3A7 into L0018:L0019, invokes LF434,
stores the startup IAC position LC62F=144 at L002C, and stores $40 at L003D.

LF434 at $F434 emits `LDAA #$80`. It stores $8000 at L000A:L000B and
L000C:L000D, then stores $80 in all sixteen BLM cells L001C..L002B. Earlier PC
code called this value 120; that was inconsistent with the emitted opcode.

Integration and frozen baselines
--------------------------------
The live PC cold reset now uses the listing-exact LF434 value 128. The existing
Step-103 out-of-range reinitialization also uses 128 in normal execution.
Explicit Step-104, Step-105 and Step-109 historical signature replays restore
their former pre-Step-113 state and retain 120 only for comparison. Those
replay values are not presented as ECM behavior.

The retained-valid/invalid helper is directly regression-tested. Full live
selection between retained states still requires a PC/HAL power-on input model;
ordinary ecm_reset remains a deterministic cold-reset test fixture.
